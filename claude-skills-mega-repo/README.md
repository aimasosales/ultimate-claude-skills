### Quality Scoring System

Each skill is evaluated across 5 dimensions:
- **Technical** (0-10): Code quality, architecture, best practices
- **Evidence** (0-10): Real-world validation, user adoption, performance metrics  
- **Originality** (0-10): Novelty, innovation, unique value proposition
- **Documentation** (0-10): README quality, examples, onboarding experience
- **Impact** (0-10): Community influence, star count, industry adoption

**Overall Score = (Technical + Evidence + Originality + Documentation + Impact) / 5**
